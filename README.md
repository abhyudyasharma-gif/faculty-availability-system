# Faculty Availability System

## Project Overview

The Faculty Availability System is a DBMS project designed to help
students check faculty schedules and availability.

The system stores faculty information, student information,
courses, timetables and faculty substitutions in a relational database.

## Technologies Used

- MySQL
- SQL
- Git
- GitHub

## Database

The database used in this project is:

FacultyAvailabilityDB

## Main Tables

1. Faculty
2. Student
3. Course
4. Timetable
5. Substitution

## Main Features

- Store faculty information
- Store student information
- Store course information
- Manage faculty timetables
- Check faculty availability
- Track faculty substitutions
- Find faculty by department
- View complete faculty schedules
- Find upcoming substitutions
- Generate department-wise statistics

## Database Relationships

Faculty → Timetable

Course → Timetable

Faculty → Substitution

Student information is maintained separately according to
department and semester.
